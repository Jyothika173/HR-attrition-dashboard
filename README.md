# HR Analytics Dashboard | Tableau

## Project Overview
This project uses Tableau to analyse employee data and understand workforce attrition, department-level trends, job satisfaction, and employee demographics.

## Tools Used
- Tableau
- Microsoft Excel

## Dataset
The dataset contains 1,470 employee records and 39 columns covering employee demographics, departments, job roles, satisfaction ratings, compensation, and attrition.

## Dashboard Features
- **Key Performance Indicators:** Employee attrition, attrition rate, and active employees
- **Department-wise Attrition:** Compare attrition across departments
- **Education Field Analysis:** Explore attrition across education backgrounds
- **Job Satisfaction:** Examine employee satisfaction ratings
- **Age Group Analysis:** Analyse employee distribution by age
- **Lollipop Chart:** Visual comparison of employee-related metrics

## Tableau Calculated Fields
- **Attrition Count:** Counts employees whose attrition status is "Yes".
- **Attrition Rate:** Calculates attrition count as a proportion of employee count.
- **Active Employees:** Calculates employee count minus attrition count.

## Files Included
- `HR-Dashboard.twb` — Tableau workbook
- `HR-Data.xlsx` — Source dataset
- `HR-Analytics-Dashboard.png` — Dashboard preview

## How to Use
1. Download the workbook and Excel dataset.
2. Open the workbook using Tableau Desktop.
3. If Tableau reports a missing data source, reconnect it to `HR-Data.xlsx`.
4. Open the **HR Analytics Dashboard** to explore the visualisations.

## Objective
To use interactive data visualisation to identify employee attrition patterns and support data-informed HR decisions.
